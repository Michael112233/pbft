Gotcha: scaling_cur_freq is an APERF/MPERF average that only refreshes when the
scheduler runs on that CPU. An IDLE core returns a frozen stale value, so a quiet
box reads ~1 GHz even with the performance governor. Always measure under load.
/proc/cpuinfo "cpu MHz" is unreliable here (reported 3700 when max was 3300).
